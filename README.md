# PlanSurf Property

A lightweight investment property manager for small to mid-size investors.

This project tracks property details, rental income, deductible expenses, depreciation, CGT, stamp duty, and land tax for Australian investment properties. It keeps the full experience local in the browser while supporting sync with the PlanSurf service backend for secure pull/push operations.

Features:
- FY-based property tracking and portfolio summaries
- Rental income and expense management
- ATO-oriented tax calculators and summaries
- Depreciation and capital works tracking
- PlanSurf service sign-in and data sync

Usage:
- Open the page in a browser or serve the repo locally
- Add your properties and transactions
- Use the cloud sync button to sign in and pull/push data from the PlanSurf service

This repo is intentionally focused on the property manager UI and logic; the service backend handles authentication and data persistence.
